# My App

A React.js website built as part of a web development course to practice component-based development, CSS styling, and interactive UI elements.

## Built With

- React.js
- JavaScript
- CSS3
- Vite

## Features

- Reusable React components
- Interactive navigation
- Course and skill sections
- CSS animations and transitions

## Getting Started

```bash
git clone https://github.com/zaheerBuilds/My-First-React-App.git
cd My-First-React-App
npm install
npm run dev
```

Open the local URL displayed in your terminal to view the website.
